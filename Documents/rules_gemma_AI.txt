RULE_ID: FS_001
CATEGORY: file_structure
APPLIES_TO: file


KEYWORDS:
file empty validation structure data presence


DESCRIPTION:
The file must not be empty and should contain metadata and data rows.


VALID:
The file contains metadata lines and tabular data.


INVALID:
The file is completely empty with no content.


REASON:
An empty file cannot be processed or validated.


RULE_ID: FS_002
CATEGORY: file_structure
APPLIES_TO: file


KEYWORDS:
file delimiter tab separated TSV format columns


DESCRIPTION:
The file must be tab-separated (TSV format), where columns are separated by tab characters.


VALID:
col1\tcol2\tcol3


INVALID:
col1,col2,col3


REASON:
Incorrect delimiter prevents correct parsing of columns.


RULE_ID: FS_003
CATEGORY: file_structure
APPLIES_TO: file


KEYWORDS:
metadata header position before data structure order


DESCRIPTION:
Metadata must appear at the beginning of the file before column headers and data rows.


VALID:
Metadata lines → column headers → data rows


INVALID:
Data rows appear before metadata.


REASON:
Incorrect file structure causes parsing and interpretation errors.

RULE_ID: TS_003
CATEGORY: timestamp
APPLIES_TO: column


KEYWORDS:
timestamp range year month day hour minute second valid limits


DESCRIPTION:
Each component of the timestamp must fall within valid ranges based on the format:
YYYY-MM-DD HH:MM:SS


YYYY (Year): valid calendar year
MM (Month): 1–12
DD (Day): 1–31
HH (Hour): 0–24
MM (Minute): 0–59
SS (Second): 0–59 


VALID:
2023-05-15 10:30:00


INVALID:
2023-13-10 10:30:00
2023-05-32 10:30:00
2023-05-15 25:00:00


REASON:
Out-of-range timestamp values are not valid calendar times.
